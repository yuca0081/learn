## go/grammar — 《Go for Java Engineers》课程

面向 Java 程序员的 Go 语言课程，每课 25–35 分钟：正文 + 翻译练习（附参考答案）+ 检索测验（即时反馈）+ 可打印速查表。

- `lessons/` — 课程页（浏览器直接打开）
- `reference/` — 速查表（Go ↔ Java 对照，可打印贴墙）
- `assets/` — 共享样式与测验脚本（页面正常显示必需，勿删）
