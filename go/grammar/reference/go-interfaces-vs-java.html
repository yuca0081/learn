接口与组合对照 Java

第 4 课配套速查表 · 建议打印贴墙 · 返回第 4 课

七条铁律

  1. 隐式实现：方法齐了就满足接口，没有 implements。
  2. 接口越小越好：标准库招牌接口只有 1 个方法。
  3. accept interfaces, return structs：参数收接口，返回给具体类型。
  4. 接口定义在消费者包里，不是实现者包里。
  5. 指针接收者的方法只有 *T 有 → 只有 *T 满足接口。
  6. 嵌入 ≠ 继承：无 is-a、无 override、无动态多态。
  7. 断言一律用 v, ok := x.(T) 双返回；分派用 type switch。

基础 idiom

type Shape interface {
	Area() float64
}

type Circle struct{ R float64 }
func (c Circle) Area() float64 { return 3.14159 * c.R * c.R }
// 没写 implements，方法齐了自动满足 Shape

func totalArea(shapes []Shape) float64 {   // 参数收接口
	sum := 0.0
	for _, s := range shapes {
		sum += s.Area()
	}
	return sum
}

var _ Shape = Circle{}               // 编译期确认实现了接口（一行单测）

方法集规则

func (c Circle) Area() float64  → Circle 和 *Circle 都满足接口
func (c *Circle) Scale(f float64) → 只有 *Circle 满足接口

var _ Shape = &Circle{}   // ✅
var _ Shape = Circle{}    // ❌ 编译错误（若有指针接收者方法）

// 铁律：方法集里出现一个指针接收者，就全用指针接收者，装 &T{}

类型断言 / type switch / Stringer

s := v.(string)       // 不符则 panic（≈ 强转）
s, ok := v.(string)   // 不符则 ok=false（安全）

switch x := v.(type) {          // ≈ instanceof 链 / 模式匹配
case string:
	fmt.Println("字符串", len(x))
case int:
	fmt.Println("整数", x)
}

func (p Player) String() string {   // ≈ toString()
	return fmt.Sprintf("%s(Lv.%d)", p.Name, p.Lv)
}                                    // fmt.Println 自动调用

nil 陷阱

接口值 = （动态类型, 动态值）一对；两者都为 nil 才 == nil。把具体类型的 nil 指针装进接口后 err == nil 为 false。返回 error：要么真 nil，要么有效错误，别返回 (*MyErr)(nil)。
