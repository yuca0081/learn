七条铁律

  1. go f() 立即返回；main 退出 = 所有 goroutine 被杀，退出前先安排等待。
  2. 无缓冲 channel 是握手（收发到齐才放行）；有缓冲 channel 是排队。
  3. channel 只由发送方关闭，且只关一次；向已关闭发送 / 重复 close = panic。
  4. 结束判断用 v, ok := <-ch 的 ok，或 for range ch 自动退出。
  5. WaitGroup 三纪律：Add 放 go 之前、Done 用 defer、Wait 等归零。
  6. select：就绪多个随机选，全没就绪阻塞；加 default 变非阻塞。
  7. 优先 channel 传数据；真要共享内存用 sync.Mutex，并跑 -race 检查。

基础 idiom：扇出—收集（本课练习的骨架）

results := make(chan int)

var wg sync.WaitGroup
for _, u := range urls {
	wg.Add(1)                 // 放在 go 之前
	go func(url string) {
		defer wg.Done()       // 任何出口都执行
		results <- len(url)
	}(u)
}

go func() {
	wg.Wait()                 // 全部完成后
	close(results)            // 由独立 goroutine 关闭（main 还在收）
}()

sum := 0
for n := range results {      // 收完自动退出
	sum += n
}

select 常用姿势

select {
case msg := <-ch:              // 等数据
	fmt.Println(msg)
case <-time.After(time.Second): // 等超时
	fmt.Println("timeout")
case <-done:                   // 等退出信号
	return
}

select {                       // 非阻塞探测
case v := <-ch:
	fmt.Println(v)
default:                       // 没就绪就走这里
	fmt.Println("先干别的")
}
