Go for Java Engineers

写给 Java 程序员的 Go 课程 · 每课 25–35 分钟 · 所有概念用 Java 对照

怎么用这套课：按顺序学，每课五步——① 读正文（概念全部用 Java 对照）→ ② 做翻译练习（先自己写，再对参考答案）→ ③ 合上资料做检索测验（即时打分，错题解析是记忆增强剂）→ ④ 60 秒闭卷回忆 → ⑤ 打印当课速查表贴墙。每课测验都会捎带前面课程的复习题，间隔重复帮你记牢。有看不懂的地方，随时回到对话里问你的 agent 老师。

环境准备

第 1 课什么都不用装：练习都在 Go Playground（浏览器里写、跑、分享）。想上本地环境，照 官方安装文档 走，然后 go version 验证；第 4 课之后做实战项目前，本地 go mod init 一套模块就够了（≈ 一分钟版的 pom.xml）。
