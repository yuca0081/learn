1 · 五个最重要的心智转变

你已经会编程了，学 Go 的主要工作量不是学概念，而是搬家——把 Java 的习惯映射到 Go 的规则上。先记住这五条，能避开 80% 的编译报错：

  1. 没有 class。数据放 struct（下节课讲），方法挂在 struct 上；组织代码的单位是包（package），文件不必一一对应一个公共类。
  2. 没有 public / private 关键字。标识符首字母大写 = 导出（相当于 public），小写 = 仅包内可见。注意"标识符"指代码里名字的首字母——函数名、类型名、变量/常量名、struct 字段名，和文件名无关（文件名惯例全小写，随意起）。所以标准库里是 fmt.Println（函数名大写，可被你调用）。
  3. 分号省略，括号省略。if / for / switch 的条件不写括号；行尾不写分号——编译器按行自动插入，所以 { 必须和语句在同一行，不能另起一行（Java 允许的 Allman 风格在 Go 里直接编译错误）。团队格式统一交给 gofmt，没有 Google Style vs 其他风格之争。
  4. 错误是值，不是异常。函数失败时返回一个 error，由调用方 if err != nil 处理（错误处理课详讲）。panic ≈ Java 的 Error，只留给真正不该发生的情况。
  5. 编译即终点。go build 直接产出单个静态二进制文件——没有 JVM、没有 classpath、没有 jar，扔到服务器就能跑。这也是后端团队喜欢 Go 的原因之一。

对照阅读：《Go for Java Programmers》第 1 章 A Brief Look at Go vs. Java（O'Reilly）。

2 · Hello, World

Java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, 世界");
    }
}
Go
package main

import "fmt"

func main() {
	fmt.Println("Hello, 世界")
}
  • package main + func main() 是程序入口，对应你的 public static void main。main 包 go run 可执行，go build 出二进制。
  • import "fmt" ≈ Java 的 import，但没有分号、没有通配符 .*；fmt 是格式化 I/O 标准库（类比 System.out 所在的那套）。
  • import 了不用的包 = 编译错误（不是 warning）。IDE 会自动帮你清理。

实操：在 Go Playground 里跑一遍，不用装任何环境。官方教程：A Tour of Go · 包、变量和函数。

包与文件组织：文件名和 Java 的什么对应？

答：什么都不对应——Go 没有"文件名 = 类名"这条规则。Java 规定一个公共类一个文件（Player.java 里必须是 public class Player）；Go 的 player.go 只是给你自己看的组织单位，里面放几个类型、几个函数都随意（惯例蛇形命名，如 http_server.go；工具链唯一在意的名字是 _test.go 后缀 = 测试文件）。真正的对应关系是包 ≈ 目录，可见性按包算而不是按文件算：

组织规则JavaGo
包与目录包路径必须匹配目录同目录所有 .go 文件第一行必须声明同一个 package；目录名 ≈ 包名（惯例）
文件名文件名 = 公共类名无约束，一个文件可放任意多个类型 / 函数
import 的对象导入类：import com.x.user.Player;导入包：import "myapp/user"，用 user.Xxx 访问其导出成员
可见性最小粒度类（private）包（小写标识符对同包所有文件可见）
包内可见默认（package-private）首字母小写
全局可见public首字母大写
myapp/
  go.mod           // 模块定义（≈ pom.xml，配置环境那节课讲）
  user/
    user.go        // package user ┐
    repository.go  // package user ├ 同一个包、同一个命名空间，
    service.go     // package user ┘ 小写成员在这三个文件间互通
  main.go          // package main

推论：Java 的 private（类内私有）在 Go 里没有对应——最小可见粒度就是包。所以 Go 社区的包通常切得比 Java 的类小得多，一个包往往只负责一件事。

3 · 变量与零值

Java 声明局部变量必须立刻初始化；Go 的变量声明即有零值（不是 null、不是未定义）：

var x int = 10      // 完整形式：var 名字 类型 = 值
var y = 10          // 类型推断（编译器知道这是 int）
var a, b = 1, "hi"  // 一行声明多个

func main() {
	z := 10        // 短声明：省略 var 和类型，只能用在函数内
	var p float64  // 声明不初始化 → 零值 0.0
	fmt.Println(z, p)
}
类型零值Java 对照
boolfalse只能自己初始化
数值（int / float64…）0—
string"" 空串Java 的 String s; 是 null，Go 不会是 nil
指针 / 切片 / map / 接口 / 函数nil≈ Java 的 null，但只属于这些类型
两个编译期铁律： ① 声明了没用过的变量是编译错误（Java 只是 warning）—— declared and not used: z； ② 不想要某个返回值时用 _ 丢弃（后面函数会用到）。这两条都是为了让编译器替你抓死代码。

常量用 const，语义同 Java 的 final：

const Pi = 3.14159
const StatusOK = 200

官方教程：A Tour of Go · 变量、常量；《Go 语言圣经》§2.4 赋值与变量。

4 · 基本类型与显式转换

类型大家族你一眼就认识，重点记三个不同：

JavaGo注意
int / longint / int64Go 的 int 是平台字长（如今普遍 64 位）；还有 int8/16/32/64、uint 系列，业务代码默认 int
doublefloat64默认选 float64
charrunerune = int32 的别名，存一个 Unicode 码点；byte = uint8 的别名
Stringstring不可变、UTF-8 编码（Java 是 UTF-16，这是重要差异，后面讲 range 时会撞上）
Objectany（即空接口 interface{}）接口课详讲

Go 没有隐式类型转换——哪怕 int → float64 这种“绝对安全”的也不行：

i := 42
var f float64 = i      // ❌ 编译错误：cannot use i as float64
var f float64 = float64(i)  // ✅ 必须显式写
n := 3
ratio := float64(i) / float64(n)  // 表达式里也各转各的

这条规则和 Java 的自动加宽（int 隐式变 double）相反，是你前两周最容易踩的坑。

官方教程：A Tour of Go · 基本类型、类型转换。

5 · 函数与多返回值

func add(a, b int) int {   // 参数类型简写：a, b int
	return a + b
}

func divmod(a, b int) (int, int) {   // 返回两个 int
	return a / b, a % b
}

func main() {
	q, r := divmod(17, 5)   // q=3, r=2
	_, r2 := divmod(17, 5)  // _ 丢弃商，只要余数
	fmt.Println(add(1, 2), q, r2)
}

多返回值是 Go 最颠覆 Java 的一个特性。Java 里返回“两个值”你得造一个包装类、或用数组下标猜含义、或用 out 参数；Go 直接返回元组，而且它马上会和错误处理擦出火花——result, err := doSomething() 就靠它：

Java
static int[] divmod(int a, int b) {
    return new int[]{a / b, a % b};
}
int[] r = divmod(17, 5);
// r[0] 是啥？读注释才知道
Go
q, r := divmod(17, 5)
// 名字自解释

// 命名返回值（小函数可用）：
func divmod(a, b int) (q, r int) {
	q = a / b
	r = a % b
	return  // 裸返回
}

另外记住 _（空标识符）：任何不想接收的值都丢给它，编译器就不报“未使用”了。

官方教程：A Tour of Go · 函数、多值返回。

6 · 控制流：if / for / switch

if：没有括号，可以带初始化语句

if score >= 90 {
	fmt.Println("优")
} else if score >= 60 {
	fmt.Println("及格")
} else {
	fmt.Println("不及格")
}

if n := x * 2; n > 100 {   // 带初始化语句
	fmt.Println(n)         // n 只在 if/else 块内可见
}
// fmt.Println(n)  ← 这里用 n 是编译错误

if n := ...; n > 100 这种“初始化 + 条件”写法你会天天见到（错误处理的标准姿势 if err := f(); err != nil 就是它），它的作用是把临时变量的作用域收窄到 if 里。

for：唯一的关键字

for i := 0; i < 5; i++ { }  // 三段式 = Java 的 for
for i < 5 { }               // 只写条件 = Java 的 while
for {                       // 无限循环，break 跳出
	break
}

没有 while、没有 do-while。三种 for 覆盖了它们的所有场景；遍历集合的第四种形态 for ... range 等学了切片和 map 再讲。

switch：默认自动 break

Java
switch (day) {
    case "周六":
    case "周日":
        System.out.println("休息");
        break;          // 忘写 break → fall through bug
    default:
        System.out.println("上班");
}
Go
switch day {
case "周六", "周日":      // 多值 case 用逗号
	fmt.Println("休息")   // 默认 break，不会穿透
default:
	fmt.Println("上班")
}

Java 的 switch 灾星“忘写 break”在 Go 里不存在：默认就是 break，想穿透反而要显式写 fallthrough。另外 Go 的 switch 没有括号，case 值还可以是任意表达式（不必是常量）。

官方教程：A Tour of Go · 流程控制（if / for / switch 三节都过一遍）。

7 · 动手练习：把 Java 翻译成 Go

任务：把下面的 Java 代码翻译成 Go。不用任何标准库函数，只用 if 和多返回值——正好覆盖本课所有要点：

待翻译的 Java
public class Util {
    // 返回三个数中的最小值和最大值
    public static int[] minMax(int a, int b, int c) {
        int min = a, max = a;
        if (b < min) min = b;
        if (b > max) max = b;
        if (c < min) min = c;
        if (c > max) max = c;
        return new int[]{min, max};
    }

    public static void main(String[] args) {
        int[] r = minMax(7, 2, 9);
        System.out.println(r[0] + " " + r[1]);  // 期望输出: 2 9
    }
}

先自己写（白纸或编辑器都行，写不出来再翻上面的章节），然后把代码贴进 Go Playground 点 Run 验证输出是不是 2 9。写完再对照答案：

查看参考答案（先自己写！） 
package main

import "fmt"

func minMax(a, b, c int) (int, int) {
	min := a
	max := a
	if b < min {
		min = b
	}
	if b > max {
		max = b
	}
	if c < min {
		min = c
	}
	if c > max {
		max = c
	}
	return min, max
}

func main() {
	lo, hi := minMax(7, 2, 9)
	fmt.Println(lo, hi)  // 2 9
}

自评清单：① 参数类型用了简写 a, b, c int？② 返回了两个值而不是数组？③ if 条件没写括号？④ 调用处用了 := 接收两个值？⑤ 没有多余的 import？——五条全中就是合格的第一份 Go 代码。

9 · 闭卷回忆

最后 60 秒，不看上文，在脑子里（或纸上）回答三个问题，然后滚动到本页底部核对：

  1. Go 声明局部变量的两种写法分别是什么？各有什么限制？

  3. 三段式 ↔ Java for；条件式 ↔ Java while；for{} ↔ while(true)。
